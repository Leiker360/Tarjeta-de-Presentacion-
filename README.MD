# 📌 Taller Práctico: Estructura Básica del Frontend (Tarjeta de Presentación)

Proyecto desarrollado para la asignatura **Diseño de Sistemas de Internet** de la Universidad Nacional de Ingeniería (UNI).

## 🚀 Descripción del Proyecto
Este proyecto consiste en el diseño, desarrollo y estructuración de una tarjeta de presentación personal interactiva utilizando **HTML5 Semántico** y **CSS3 Moderno**, cumpliendo con los estándares de organización del frontend, accesibilidad y diseño adaptativo (*responsive*).

## 🛠️ Archivos del Repositorio
* `index.html`: Estructura principal con el contenido personal, imagen y secciones semánticas.
* `style.css`: Estilos modernos personalizados con la paleta *Dark Slate / Sapphire Tech*.
* `README.md`: Documentación del proyecto.

## 🌐 Cómo visualizar el proyecto
1. Clona este repositorio o descárgalo en tu equipo.
2. Abre el archivo **`index.html`** en cualquier navegador web moderno (Google Chrome, Firefox, Edge).
